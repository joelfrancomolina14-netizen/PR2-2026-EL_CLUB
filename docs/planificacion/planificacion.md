# Planificación del Proyecto — EL CLUB

Este documento define las fases, hitos y entregables del proyecto **EL CLUB**, complementando el cronograma detallado en [`gantt.md`](gantt.md).

## 1. Hitos Principales
- **Hito 1 — Análisis y Requisitos:** Definición de visión, alcance, requisitos funcionales/no funcionales e historias de usuario.
- **Hito 2 — Diseño y Base de Datos:** Modelado lógico (`10-09-MODELOLOGICOOFICIAL`) y construcción del script DDL ejecutable (`database/script_elclub.sql`).
- **Hito 3 — Estandarización del Repositorio:** Configuración de estructura estándar, documentación técnica, plantilla de Pull Requests, Issues y controles de calidad.
- **Hito 4 — Desarrollo de Capas y UI (Windows Forms):** Implementación de acceso a datos (DAL), lógica de negocio (BLL) e interfaz de escritorio en C#.
- **Hito 5 — Pruebas y Entrega Final:** Validación funcional, pruebas de integración con base de datos y presentación final.

## 2. Estrategia de Iteraciones
- Trabajo incremental organizado mediante **Issues** en GitHub asignados a cada integrante.
- Cada cambio se desarrolla en ramas dedicadas (`feat/...`, `fix/...`, `docs/...`) y se integra mediante **Pull Requests** revisados por el equipo.
